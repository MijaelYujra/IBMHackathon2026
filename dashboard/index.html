02 / FLAGSHIP PROJECT
IBM BOB 2.0MCPTERRAFORM

Drift Detector

An AI-assisted safety layer that compares Terraform with observed infrastructure, detects drift, explains its risk, and prepares a remediation for human approval.

The hackathon prototype generates its declared state from real Terraform plans and uses a simulated cloud state, so the demo is safe, reproducible, and credential-free.
